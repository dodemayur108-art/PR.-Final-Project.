# 📊 Data Intelligence Dashboard

Welcome to the **Data Intelligence Dashboard** project! This project demonstrates an end-to-end data analysis and interactive reporting solution built entirely using **Microsoft Excel**. It processes customer transaction records to extract key business insights, perform predictive analysis, and present findings visually.

---

## 🎯 Project Objective

To build an interactive, full-fledged Excel dashboard and reporting solution that analyzes customer transaction data, tracks key performance metrics, generates business insights, and aids data-driven decision-making.

---

## 📁 Dataset Overview

* **Source Sheet:** `Final Project Dataset`
* **Records:** 200+ customer transaction entries
* **Key Fields:** Customer details, Transaction Dates, Purchase Volumes, Revenue, and Product Categories.

---

## 🛠️ Key Topics & Techniques Implemented

### 📅 1. Date & Time Analysis
* Utilized dynamic date functions: `TODAY()`, `NOW()`, `DATEDIF()`, and `EOMONTH()`.
* Implemented automatic **Timestamps** using `NOW()` paired with iterative calculations.

### 🔍 2. Advanced Data Manipulation & Lookup
* **FILTER Function:** Dynamic multi-value returns for custom data views.
* **Text Functions:** Created custom abbreviations and cleaned string formatting.
* **List Comparison:** Automated logic to compare two lists and extract matching entries into dedicated columns.
* **Frequency Analysis:** Identified top repeating customer names and most frequently purchased products via formulas.

### 📈 3. What-If & Predictive Analytics
* **WHAT-IF Analysis:** Scenario Manager & Goal Seek for financial planning and decision forecasting.
* **Linear Regression:** Trend analysis and forecasting using the *Data Analysis Toolpak*.

### 🎨 4. Data Visualization & Dashboarding
* **Pivot Tables & Pivot Charts:** Dynamic visualization using Bar, Line, and Pie charts.
* **Interactive Controls:** Slicers and Timelines for seamless filtering.
* **KPI Indicators:** Conditional Formatting using custom icon sets and indicator arrows to highlight performance thresholds.
* **GroupBy Logic:** Advanced formula-based customer grouping to identify High-Value Customers.

## 🚀 How to Use

1. Open the file `PR_Final_Project_Data_Intelligence_Dashboard.xlsx` in **Microsoft Excel**.
2. Navigate to the **`Dashboard`** tab to interact with visual charts and KPI metrics.
3. Use the interactive **Slicers & Timelines** to filter data by date ranges, regions, or categories.
4. Check the **`Analysis`** sheet for regression outputs, What-If scenarios, and dynamic formulas.
